# Calendrier

**Jusqu'au dimanche 18 octobre, le format est simple** : trois shorts par semaine depuis le 28 septembre, **le lundi, le mercredi et le vendredi ou le samedi**, sur Instagram, TikTok et YouTube Shorts, tous de [[La série · ce qui annule ton déficit|la série]] ; la vie de tous les jours dans les stories ; une session de tournage par semaine, le dimanche après la sortie longue. Les longues YouTube reprennent après le semi. Chaque événement a sa note : clique-le dans la grille, ou glisse-le pour changer sa date. Le nom de la vidéo dans la case ouvre la page de la vidéo.
