# Calendrier

**Jusqu'au dimanche 18 octobre, le format est simple** : deux ou trois shorts Instagram par semaine selon ton temps (décidé le 23 septembre), le samedi en priorité, sur des sujets libres ; la vie de tous les jours dans les stories ; une session de tournage par semaine, le dimanche après la sortie longue. Les longues YouTube reprennent après le semi. Chaque événement a sa note : clique-le dans la grille, ou glisse-le pour changer sa date. Le nom de la vidéo dans la case ouvre la page de la vidéo.
